# formal_run_001 可复现性审计与 README 设计

## 目标

检查 `formal_run_001` 中正式训练、冻结测试、行为分析、认知模型拟合和 actor 反事实学习率代码是否能够在当前环境按文档启动并产生预期结构；为审稿人和实验室成员编写可独立核验的说明。

## 验证范围

1. 静态检查所有主链 Python、R 和 Stan 文件的导入关系、入口参数、路径假设和输入输出。
2. 运行 Python 模块导入、所有主入口 `--help` 和核心 `selfcheck`。
3. 在专用临时目录运行最小训练与冻结测试，检查 checkpoint、CSV、NPZ 和 manifest。
4. 使用已有正式数据重跑行为分析及 actor 直接反事实分析，并与已保存汇总结果核对。
5. 检查 R、CmdStan 和 Stan 模型的可用性；编译模型并运行现有拟合诊断，但不重新执行全部正式 MCMC。
6. 所有本轮生成的临时产物验证后删除；既有正式产物只读。

## README 结构

- 根 `README.md`：端到端导航、环境安装、快速验证、完整复现顺序和各链验证状态。
- `formal_osla/README.md`：核心模型、训练、验证选模、冻结测试和输出格式。
- `analysis/behaviour_analysis/README.md`：行为与训练曲线分析的输入、命令、输出和核验标准。
- `analysis/fitting_NN/README.md`：数据抽样、RDS、M1–M3、Stan 诊断、模型比较和已知限制。
- `analysis/counterfactoral_lr/README.md`：反事实分支、指标、分母支持域、质量控制和结果文件。

## 判定与报告规则

- “已验证”仅用于本轮实际成功运行的命令。
- “已有产物核对”用于读取并检查既有正式结果，但未重跑全部计算的步骤。
- “未验证”或“需外部依赖”明确记录缺失软件、数据或长时计算限制。
- 若发现错误，优先修复阻断复现的路径、导入和参数问题；不改变模型设计、统计口径或正式结果。

## 安全与清理

临时目录必须是本轮新建并记录的专用目录。删除前核对其解析后的绝对路径位于该专用目录内；不得删除或覆盖 `outputs/output_formal`、正式 checkpoints、冻结测试数据、Stan fits 或现有汇总结果。

## 完成标准

- 五份 README 与实际代码一致，命令可复制，明确运行目录、依赖、预计产物和成功判据。
- 主链验证结果形成简洁审计记录，列出通过项、修复项和未完成项。
- smoke-test 临时产物已安全清理，正式产物保持不变。
